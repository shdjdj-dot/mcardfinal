# M Card PWA recreation

A front-end recreation of the M Card / ticket-wallet interface shown in the supplied demo video.

## Included
- Splash/loading screen
- Ticket Wallet with active U19 annual bus ticket
- Refresh/loading-ticket interaction
- Open Ticket full-screen ticket view
- Live countdown to 31/07/2027
- Live current time
- QR-style demo code
- ID reminder
- Bottom navigation: Wallet, Buy Tickets, Smartcard, Profile
- Basic Buy Tickets selection and demo purchase action
- Smartcard and Profile screens
- PWA manifest + service worker
- iOS home-screen icon assets

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## GitHub Pages / iOS
Push the contents of this folder to a GitHub repository and enable GitHub Pages for the repository. Open the Pages URL in Safari on iPhone and use **Share → Add to Home Screen**.

This is a UI recreation/demo. The purchase button and QR are not connected to a real ticketing system.


Latest update: loading logo uses transparent artwork so its dark area matches the splash background; ticket logo uses a vertical card treatment matching the reference video and is exactly the same height as the QR code, with a continuous rocking animation.
